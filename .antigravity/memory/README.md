# Memory

Verzeichnis für Berichte, Erkenntnisse und Findings aus vergangenen Sessions — damit künftige Sessions nicht bei null starten.

## Konvention

- Eine Datei pro Thema/Incident, benannt `YYYY-MM-DD-kurztitel.md`.
- Wichtig sind: Kontext, Ursache, Lösung, und **wiederkehrende Fallstricke** (Dinge, die man nicht nochmal debuggen will).

## Inhalt

- Noch keine Einträge. Nach dem ersten relevanten Incident/Bugfix hier ablegen.
